# 上线前安全审计清单

**状态：未来验收清单，尚未完成。** 勾选需要代码、配置、运行环境和可重复测试证据；文档存在不等于通过审计。

## 密钥与密码学

- [ ] 分离身份签名、设备认证与密钥协商用途；审核算法、编码、版本与密钥目录。
- [ ] 验证私钥/对称密钥只在受控 Keychain 或等价硬件边界，不入日志、SwiftData、备份和崩溃报告。
- [ ] 经独立审查的预密钥握手、认证、重放保护、乱序处理与密钥轮换；只在证据充分时宣称前向保密。
- [ ] 覆盖账号删除、好友删除、设备撤销、恢复和异常中断的密钥清理与可恢复性。

## 数据、备份与权限

- [ ] 核查 SwiftData、附件、搜索索引、缓存、系统备份和临时文件的明文残留。
- [ ] 校验备份 KDF、AEAD、格式版本、账户绑定、恢复原子性和损坏文件处理。
- [ ] 后端逐端点校验会话成员、目标设备、文件对象所有权和最小权限。
- [ ] 明确元数据、对象存储、数据库备份、审计日志的保留与删除策略。

## 网络与运营

- [ ] TLS/WSS 校验、设备挑战签名、短期 token、刷新轮换、撤销与泄露演练。
- [ ] UserID 枚举、暴力注册、好友请求骚扰、垃圾消息、限流与统一错误测试。
- [ ] 游标幂等、断线重放、乱序、事件伪造、删除墓碑和多设备冲突测试。
- [ ] APNs payload 与应用日志无消息正文、附件名、私钥或 bearer token。
- [ ] 渗透测试、依赖更新、密钥/事故轮换预案、监控告警与安全事件响应演练。

上线评审应记录每项负责人、证据链接、遗留风险与接受决策。当前代码仅提供本机基础，不能把以上项目提前标记为完成。
