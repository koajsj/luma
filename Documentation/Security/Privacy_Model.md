# 隐私模型

## 当前本机（已实现）

消息正文、草稿、用户昵称/头像/简介、好友昵称/头像/备注/私密笔记/本地限制标记、隐私偏好、搜索索引及附件元数据使用本机主密钥加密后存储。密码/PIN 为带盐验证值；Master、Identity、Device、Session、PreKey 和链密钥材料在 Keychain。备份用独立密码加密，恢复需同一 UserID，不包含登录状态、密码验证值、Face ID 数据或 Keychain 密钥。

**仍可见**：UserID、联系人/会话关系、消息类型/时间/状态/数量、设备信息等 SwiftData 元数据。精确账号搜索使用规范化 UserID 与设备 Keychain 随机密钥计算的 HMAC-SHA256 索引，旧账号解锁后清空 SHA-256 索引；UserID 本身仍以明文保存，不能称为匿名化或加密。后端索引使用独立环境密钥，数据库泄露者无法仅靠公开哈希字典推断索引，但同时取得环境密钥或明文 UserID 时不具备这项保护。旧版明文资料字段在账号解锁后迁移；迁移前及 SQLite 历史页、系统备份中的旧副本不保证被物理擦除。在线资料同步仍会向后端提交用户公开昵称。隐私护盾在截图后生成仅本机的事件；系统报告录屏、镜像或 AirPlay 捕获时覆盖界面，进入后台时显示占位内容。它不能阻止截图，也不能保证覆盖所有屏幕采集路径；未接入通知服务时不能通知对方。受保护聊天需要额外解锁，不进入本地搜索或收藏摘要；聊天锁仍是 UI 门禁，不是独立会话加密。通知预览控制目前仅预留策略接口。

## 后端可见范围（基础工程，未部署）

| 服务端可见或可能推断 | 服务端不应获得 |
| --- | --- |
| UserID、公开资料、公钥、设备列表、好友/会话路由、消息时间/大小/版本、在线心跳、IP、推送 token、密文与文件密文 | 消息/附件明文、明文文件名、本地密码和 PIN、Face ID 数据、Master Key、Identity/Device/Session/PreKey 私钥或对称密钥 |

在线登记和资料/好友请求会向指定后端发送公钥、UserID 等必要元数据。正式聊天目前不会上传 v1/v2 本机密文。“看不到内容”以客户端真正完成可验证 E2EE 且无明文上传为前提；当前本机 v2 并不满足这一条件。密文不隐藏通信关系、时间、频率或大小。在线状态、最后上线、已读回执和消息预览应遵守用户开关；隐私模式覆盖对外展示。APNs 仍未启用。

搜索服务必须执行精确 UserID 查询，关闭 `searchable` 时不可被发现，并用限流降低枚举。日志和分析事件只记录必要操作元数据，设保留期限与删除流程。服务器删除消息/附件应处理存储、缓存、备份与墓碑保留期，但无法保证已经下载到其他设备的副本被远程擦除。
