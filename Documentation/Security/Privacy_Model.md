# 隐私模型

更新：2026-10-26。依据当前源码与[安全治理记录](Privacy_Boundary_Governance_2026-10-22.md)，不代表已检查真实设备流量、生产日志或完成外部审计。元数据匿名化不在当前范围。

## 数据位置与可见性

| 数据 | 设备本地 | 后端及其运维方 |
| --- | --- | --- |
| 消息正文、敏感编辑/删除/已读/Reaction 载荷 | v4 解密后使用本机 Master Key 加密落盘；展示时存在内存明文 | 逐设备密文信封；可见事件类型、设备路由、时间/大小/版本 |
| 图片、文件、语音及文件名 | 随机附件密钥加密；密钥/文件名放入 v4 密文消息与本机加密描述，缓存再次本机加密 | 文件密文、对象标识、大小和哈希；不上传明文文件名/缩略图 |
| Master、Identity/Device/Session/PreKey 私钥、Ratchet 密钥材料 | 本设备 Keychain；附件秘密也受本机加密描述保护 | 不上传、不存储；公钥和签名可见 |
| 本地密码、PIN、Face ID | 密码/PIN 为带盐验证值，生物识别由系统处理 | 不上传；在线认证使用设备签名而非本地密码 |
| 昵称、头像/简介、备注、私密笔记和隐私偏好 | 敏感字段由主密钥加密；旧资料解锁后迁移 | 明确发布/同步的公开资料可见；本地备注/私密笔记不应上传 |
| UserID、好友/会话/设备关系、消息类型/时间/状态 | 必要 SwiftData 元数据仍明文；精确本机搜索索引用 Keychain 密钥 HMAC | UserID 与关系可见；搜索 HMAC 使用独立环境密钥，但数据库仍有明文 UserID |
| 搜索索引、草稿、附件元数据 | 主密钥加密；搜索运行时解密 | 本地索引不上传 |
| Access/Refresh Token | Keychain；注销立即清除，无 Token 撤销标记可用于后续补偿 | 只持 Token 哈希、设备和会话元数据；请求时会接触实际 Token，不得记录 |
| Presence、已读策略、IP | 本机偏好与在线服务策略并非全部已同步绑定 | 可接触 IP、设备最近活动及临时在线/输入状态；展示受好友、block、撤销与服务端开关限制 |
| 推送 token/通知 | APNs 仍未正式接入 | 预留表/接口不代表已采集实际 token；未来只能使用通用通知，不带正文/联系人信息 |

“服务端只持密文”针对通信内容，不包括公开资料、UserID、关系及运行元数据。哈希/HMAC 不等于加密或匿名化。服务器被恶意控制仍可收集其可见数据、隐藏设备、拒绝或延迟服务；不能仅靠 HTTPS 推断身份目录可信。

## 用户控制与实际边界

- `searchable=false` 的陌生用户搜索不返回资料；精确查询、限流及 block 检查降低枚举/骚扰，不承诺 UserID 无法猜测。
- 身份核对现在使用 v4 公钥束的账号签名、设备绑定与预密钥签名；账号/设备公钥签名及本机指纹/版本固定仍不证明完整设备列表或跨设备一致。首次安全码必须经可信带外渠道比较；点击“信任”本身不是独立验证。透明目录尚未实施，详见[威胁模型](Threat_Model.md)。
- 登记/撤销在后端串行账号变更并重新检查审批设备，拒绝已撤销操作者的迟到请求；这只保护现有 API 权限，不是完整集合的签名授权。目录方案还需独立固定的必需 auditor、真实证明套件和可靠的签署状态恢复；长期离线/客户端状态丢失不能仅凭主服务器提供的旧签名重新获得“已验证”。
- [目录接入合同](../Protocol/Client_Server_Protocol.md#可信密钥目录接入合同-v12026-10-23未接入生产)中的见证状态/迁移要求仍非线上能力；离线检查器只读公开状态投影，不处理私钥或上传数据。历史内容可读不等于已撤销设备仍有权新发送；新鲜度窗口也不等于即时获知所有撤销。真实证明、独立见证恢复和认证上下文都通过前不能宣称目录闭环。
- 已读关闭时不发送已读事件；未经端侧认证的 v3 远端删除/已读不改变消息状态。新在线写入只接受 v4；旧 v3 事件仍可能来自既有同步队列，必须按历史认证边界处理。服务器送达只是 v4 传输提示。
- 本地在线状态、最后上线和隐私模式选项目前控制本机模拟展示；尚未全面绑定后端 `show_presence`，不能承诺切换本机开关等于停止所有后端心跳。后端默认不公开在线状态，设备管理仍保留最近活动。
- Chat Lock 是额外 UI 门禁，受保护聊天不进入本地搜索/收藏摘要，不是独立消息密钥体系。Privacy Shield 可在系统报告截图后记录本地事件，录屏/镜像或后台时遮罩；不能禁止截图、检测所有采集路径或在未接同步时通知对方。
- 通知内容预览仍是策略预留，不代表已运行 APNs；当前未实现的开关效果不能作为锁屏内容保护证明。

## 本地存储、删除与生命周期

Keychain 使用 `WhenUnlockedThisDeviceOnly`，不随常规备份跨设备恢复；Face ID 为应用门禁，而非每条密钥的独立生物识别 ACL。锁屏/后台/账号切换通过授权代次与迟到回调复核限制访问；真实设备的系统行为仍待验收。

本地迁移先验证密文再清空旧字段，失败保留原数据。附件下载后复核当前账号、锁定及消息删除状态，再解密/写缓存；临时文件与缓存有本机加密和系统文件保护。复制正文限定本机并设置两分钟过期。上述措施不承诺清除所有系统内存、SQLite 历史页、系统历史备份或用户主动导出的副本。 v4 消息到期后清理正文和附件，并保留隐藏的作者/路由/revision 墓碑，用于验证迟到控制事件及推进原接收链；它不作为可恢复正文或搜索结果。现存已删记录会在授权解锁时补充独立的本机加密证据；迁移保留原受保护内容以便失败回滚，不伪称远端认证删除。消息行再次缺失时只能恢复空隐藏行，不能恢复正文、附件或 Reaction。完全缺失证据的旧数据仍安全暂停同步；旧备份不能覆盖现存墓碑或在线会话状态。详见治理记录的“历史墓碑迁移与同步恢复”。

删除消息清理本地附件描述/缓存，并通过授权的 v4 事件撤销服务端下载权限、异步清理密文；对象存储与数据库不是原子事务，失败留墓碑重试。已经下载到其他设备的内容不能保证被远程擦除。注销清除本机 Token，离线签名撤销需要后端恢复可达；无法确认远端撤销时不能表示注销已立即使所有远端会话失效。

## 备份保护

- **iOS 便携备份**：独立口令派生与 AES-GCM，含必要用户数据，不含 Keychain 私钥、Token、PIN/密码验证值或 Face ID。在线历史/同步进度导出与覆盖受限，避免生成不可恢复的在线副本。弱口令仍有离线猜测风险，丢失唯一设备且无预备恢复材料可能永久丢失身份/会话私钥。
- **VPS local 模式**：age 加密 PostgreSQL 和 storage 备份，私钥留在受限服务器目录以支持无人值守补偿；完整 VPS 失陷时攻击者可能同时得到私钥与备份。
- **VPS offline 模式（显式选择）**：新备份只给独立接收公钥加密，旧本机私钥不能解密这些新备份；不自动迁移/删除旧备份或旧钥。维护临时提供 tmpfs/ramfs、无 swap 中的私钥，无法同时承诺无人值守解密恢复。维护期间 root 仍可窃取秘密，须异地验证并保管可信副本/摘要。age 完整性不证明来源。操作及兼容规则见[部署指南](../../deploy/README_DEPLOY.md)。

## 服务端权限、日志与未完成事项

默认 Compose 已将长期 API 固定为独立 `luma_api`，原初始化管理员仅供 PostgreSQL 和短时迁移/授权任务使用。恢复后必须重新授权，旧管理员 API 版本回滚受兼容门禁；不自动转换旧数据卷所有权。隔离 PostgreSQL 授权/恢复通过不代表 Docker/Ubuntu 全生命周期已验收或真实部署已切换。应用 DML 仍可接触其全部表数据，API 必须保留对象授权。

所查日志代码不主动记录 Token、私钥、消息/文件内容或敏感请求体；短时角色设置同时关闭 PostgreSQL 语句/时长采样日志，凭据不经命令参数；实际运维采集、崩溃诊断和备份留存策略仍需部署者审核，不假设已有自动保留期或已完成物理擦除。

Recovery 默认关闭，不启用生产 E2EE 标识。真实双设备、Face ID、完整故障注入、隔离 Ubuntu 灾备和独立密码学审计仍未完成。
