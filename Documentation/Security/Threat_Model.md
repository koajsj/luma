# 威胁模型

## 资产与信任边界

保护对象为消息/附件正文、身份与会话私钥、本地备份、账户控制权。边界包括已锁定/已解锁设备、Keychain 与 SwiftData、客户端与后端、后端与对象存储/APNs。后端基础工程尚未部署；v4 在线文字和控制事件已通过两个独立 iOS 模拟器与隔离本地 HTTPS 后端联调。测试中的身份指纹来自后端目录，并未通过真正独立的线下渠道验证；以下服务端攻击分析仍需上线评审。

| 威胁 | 当前实际边界 | 未来应对 / 剩余风险 |
| --- | --- | --- |
| 数据库或对象存储泄露 | 显式在线 v4 聊天上传逐设备消息/事件密文及已加密附件；本地模式不上传。本机 SwiftData 部分路由元数据仍明文。 | 限制数据库权限并加密备份；仍泄露关系、时间、大小等元数据。 |
| 手机丢失 | Keychain `WhenUnlockedThisDeviceOnly`，PIN/Face ID 门禁与后台隐藏。 | 设备解锁或运行时被控时仍可能读内存明文；需设备撤销、会话轮换、备份恢复流程。 |
| Master/Identity/Session 密钥泄露 | 私钥/密钥在 Keychain；本机 v2 保留根密钥，无法宣称前向保密。 | 限制生命周期、密钥目录变更提示、经审计的握手与密钥擦除；设备完全失陷不可由服务器弥补。 |
| 中间人攻击 | 在线接口要求系统验证的 HTTPS，并有设备签名证明。 | 真实 E2EE 还需可信密钥目录、签名验证和身份指纹核验。 |
| 恶意服务器 | 可接触登记公钥、资料、好友元数据和 v3 逐设备消息密文；客户端要求人工核对身份指纹，验签后才解密。 | 服务端仍可阻断、延迟或观察元数据；旧版未绑定 revision 的编辑事件与服务端路由事件仍需迁移和独立审计。 |
| 暴力注册/UserID 枚举/骚扰 | 后端基础接口有精确搜索与限流；未完成公开环境压力评估。 | 检查账号配额、请求骚扰和屏蔽策略。 |
| Token 泄露 | iOS token 在 Keychain，短期令牌需设备签名证明；未完成真实联调审计。 | 审计刷新轮换、撤销与日志脱敏。 |
| 备份泄露 | 密码派生密钥 AES-GCM 加密；不含 Keychain 私钥。 | 离线口令猜测仍有风险；密码强度、KDF 参数与恢复一致性需评估。 |

## 未解决的安全工作

旧 v2 PreKey 未加入会话根密钥，基础链可从保留根重算；它不提供前向保密。v4 已将预密钥、逐消息 Ratchet 和认证事件接入客户端链路，但当前联调未证明恶意服务器下的公钥可信性，也未覆盖实体设备与所有中断场景。发布前仍需独立协议审查、可信身份核验或透明目录、故障注入、多设备撤销与跨设备迁移验证。服务端“只存密文”不自动防止换钥、拒绝服务或流量分析。

v4 附件代码把随机附件密钥包入逐设备消息密文，本机元数据与缓存使用 Master Key 加密。局部测试证明三类附件的 AES-GCM 错钥/篡改拒绝；真实双设备上传、下载、删除与断线恢复未验收。对象上传成功后若进程在保存对象 ID 前崩溃，可能留下待清理的孤儿密文对象。手工安全码或二维码核对依赖用户通过服务器外渠道取得对方信息；仅浏览本机显示或扫描自己的二维码不构成身份验证。

2026-09-27 最终验证轮只有一台不可用的已登记实体 iPhone，未执行双实体设备在线链路。通过的证据限于 iOS 模拟器聚焦测试、Go 编译和隔离 PostgreSQL 后端处理器测试；未完成端到端真机取证、附件中断故障注入、缓存/备份动态泄露检查或独立安全审计。安全报告与产品标识必须继续明确此边界。

本轮发现可导出但不可恢复的在线历史备份可能额外复制 v4 附件密钥描述；现已在便携备份导出前拒绝含 v3/v4 在线消息、同步进度或待发项的账号。已有本地备份格式与恢复流程不变。该修复不等于完成备份和本地缓存的动态泄露审计。

本轮加固把 v4 控制事件的设备、会话、版本和认证载荷校验集中到客户端验证入口；后端只处理密文和路由信息，仍可延迟、丢弃或重排事件。后端清理孤儿附件前先在数据库写墓碑，避免与消息关联竞态；超过 24 小时未关联的已验证密文对象会被回收。Keychain 事务标记提高中断可观察性和幂等恢复能力，但不消除系统间非原子提交、运行时内存明文、设备失陷与恶意公钥目录的风险。Debug 诊断只显示状态元数据，Release 不提供入口；诊断数据仍可能暴露关系和时间线，不应加入遥测。

Final Hardening 增加 v4 会话版本高水位与保存时的回退拒绝，防止单条旧会话记录覆盖已提交 Ratchet 状态。高水位同样位于 Keychain，整机失陷或整体 Keychain 回滚不在其保证范围内。一次性 PreKey 库存耗尽现在阻止新握手；客户端可查询本设备库存并补充，服务端无法借此证明其提供的公钥目录完整可信。已屏蔽关系不能读取 v4 公钥束。附件密钥仍只在本地主密钥加密的描述和逐设备认证密文中；已下载副本、崩溃瞬间的孤儿密文以及用户设备运行时内存仍是剩余风险。
