# Luma 产品需求文档

## 定位与理念

Luma 是以 Apple 原生体验和本地优先为基础的一对一隐私聊天客户端。默认可在一台设备上使用本地账号、好友和聊天；显式在线模式可接入独立后端发送逐设备密文。后端尚未生产部署，双实体设备与独立安全审计未完成，不能把局部联调结果表述为完整 E2EE 发布验收。

设计原则：默认少暴露、敏感字段先加密再落盘、解锁后才读取内容、失败时明确提示、功能状态可被用户理解。服务器方案不得要求上传密码、私钥、Master Key 或 Session Key。

## 用户体系

**已实现**：本机唯一的 UserID、本地密码验证、可修改昵称和头像/简介；UserID 创建后没有常规修改入口。密码为带随机盐的 PBKDF2-SHA256 验证值，PIN 验证值在 Keychain；Face ID 仅作为本机门禁。本机精确发现使用 Keychain 密钥计算 HMAC-SHA256 索引；后端精确搜索使用独立环境密钥。`searchable` 默认关闭，关闭时不能被陌生人精确搜索。

**在线基础已实现**：后端全局唯一 UserID、设备签名登记与登录、精确查找和限流；客户端可显式登记并使用这些接口。尚未生产部署或完成公开环境的防枚举评估。本机密码不能当作服务器凭据。实际接口见 [OpenAPI](../../backend/openapi/openapi.yaml)。

## 功能范围

| 能力 | 状态与边界 |
| --- | --- |
| 本地聊天 | **已实现**：文字与模拟附件、草稿、回复、编辑、删除、转发、收藏、Emoji 回应、置顶、未读数、已读设置；本机状态不代表远端送达。 |
| 好友 | **已实现**：本机账号搜索、联系人及加密备注；显式在线模式可使用后端好友请求。扫码/邀请流程尚不可用。 |
| 隐私控制 | **已实现**：PIN/Face ID、聊天锁、隐私模式、消息预览与后台隐藏、截图/录屏本机检测开关；不能阻止截图或通知对方。 |
| 本地数据保护 | **已实现**：消息、资料和选定私密字段 AES-GCM、Keychain 密钥、加密搜索索引、密码加密备份；并非整库加密。 |
| 会话密码学 | **局部验证**：v2 为本机模拟；v4 有逐设备握手、Ratchet 链和认证密文。文字及控制事件在隔离后端和两个模拟器上通过；实体设备、附件完整闭环及独立审计未完成。 |
| 通信 | **部分实现**：设备认证、好友确认、密文转发、游标同步和 WebSocket 提示；APNs 和生产多设备验收尚未完成。 |

## 隐私原则与 UI

聊天采用 SwiftUI、系统导航、TabView、SF Symbols、系统蓝/灰消息气泡，兼容浅色/深色与 Dynamic Type。聊天顶部继续显示“隐私保护已开启”；模拟在线/正在输入状态须标注模拟。隐私中心集中呈现可理解的设置，已读回执关闭时不得发送对外回执。

## 阶段规划

当前基线是本机可用客户端、后端基础工程和显式在线 v4 路径。下一阶段需完成双实体设备、附件与中断恢复的完整验收，以及独立协议审查、公钥目录透明性和上线准备。详见[路线图](Feature_Roadmap.md)。
