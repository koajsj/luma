# 功能路线图

此表按当前仓库可见实现记录，不以阶段名称推断完成度。状态随代码交付更新。

| 能力 | 状态 | 现有范围 / 下一道门槛 |
| --- | --- | --- |
| 本地聊天与消息状态 | **已实现** | SwiftData、本机回执、编辑/回复/回应等；无远端确认。 |
| 本地加密 | **已实现** | 消息、用户资料、好友私密字段、草稿、部分偏好和索引加密；UserID 等元数据仍可见。 |
| Identity Key、Device Key | **已实现** | P-256 本机密钥对，私钥在 Keychain；在线登记可上传公钥，目录可信验证尚未完成。 |
| Session 基础 | **已实现** | 旧 v2 为本机模拟；显式在线 v4 有经身份核对后的逐设备会话与 Keychain 状态恢复。 |
| PreKey | **已实现** | 旧 v2 不使用一次性 PreKey；v4 从后端取得并验证设备预密钥束。 |
| Ratchet 基础 | **已实现，局部验证** | v4 独立收发链已验证重开、乱序和重放；双实体设备、故障注入及独立审计待完成。 |
| Sync 架构 | **已实现的接口与 Mock** | MessageEvent、Mock 同步仍保留；v3 `RemoteSyncCoordinator` 逐事件落盘和 ack 已在隔离后端与模拟器双账号验证。 |
| 加密备份 / 本地搜索 | **已实现** | 备份不含 Keychain 密钥和真实附件文件；搜索只在解锁后的本机进行。 |
| Go 后端、PostgreSQL、Redis、密文文件存储 | **已有基础工程** | 代码位于 `backend/`；本地磁盘存储为当前方案。隔离环境验证文字链路，尚未生产部署。 |
| iOS 在线账号/好友接口 | **部分实现** | 设置页自愿登记设备、签名登录、资料和好友请求；聊天页可显式切换在线 v4 模式。 |
| WebSocket、APNs | **部分实现 / 未来计划** | iOS WebSocket 接口可收到提示；聊天页当前定时同步。APNs 仍只有后端预留接口。 |
| v3 逐设备消息信封 | **历史读取兼容** | 保留旧密文读取；新显式在线消息采用 v4。 |
| v4 文字与控制事件 | **隔离联调通过** | 两台模拟器经本机 HTTPS 后端验证双向文字、编辑、删除、已读和 Reaction；仍缺双实体设备与独立安全审计。 |
| v4 附件 | **代码已接入，局部验证** | 图片、文件、导入语音由客户端独立密钥加密；尚缺双设备经后端的完整附件与异常恢复验收。 |
| 完整多设备与正式 E2EE 标识 | **未完成** | 仍需双实体设备、目录透明性、崩溃/断网故障注入和独立协议审计。 |

## 建议交付顺序

1. 对照 [威胁模型](../Security/Threat_Model.md)、[消息格式](../Protocol/Message_Format.md) 和实际 OpenAPI 冻结 RC 安全边界。
2. 用两台实体设备验证注册、身份核对、v4 文字/附件/控制事件及重启、断网恢复。
3. 完成密钥目录透明性、恶意服务器场景和独立协议安全审计；通过后再评估 E2EE 产品标识。
4. 上线前完成 APNs、监控、备份恢复演练和生产部署验收。
